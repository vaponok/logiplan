# Logiplan

Программа для логистики в Foxhole: распределение квоты по подразделениям,
написание квоты по картинкам и таймеры складов. Языки — русский, английский,
французский.

## Скачать

**[logiplan.exe](https://github.com/vaponok/logiplan/raw/main/logiplan.exe)** — один файл, установка не нужна, просто запустить.

Нужен WebView2: в Windows 11 он встроен, в Windows 10 обычно уже установлен
вместе с обновлениями.

Настройки хранятся в `%APPDATA%\com.vaponok.logiplan\settings.json`. При первом
запуске программа сама переносит настройки старой версии (Combined Foxhole Tools).

## Что внутри

- **Распределитель** — «Рассчитать квоту» по содержимому склада, деление
  квоты между подразделениями, МТО и Лётным отделением, ресурсы на завод.
- **Написание квоты** — квота кликами по иконкам предметов.
- **Таймеры складов** — 50-часовые таймеры резервных складов с гексом,
  складом и паролем.

## Исходники

Всё в папке [`source/`](source) — там же описание для разработки.
exe в корне пересобирается автоматически после каждого изменения исходников.
