# Combined Foxhole Tools — версия на Tauri

Перенос программы `progakvoti` (Python + PyQt5) на **Tauri 2 + Svelte 5 + TypeScript**.
Три вкладки, как раньше: «Распределитель», «Написание квоты», «Таймеры складов»;
три языка (RU / EN / FR); своё окно без системной рамки.

|                     | Было (PyInstaller)          | Стало (Tauri)                     |
|---------------------|-----------------------------|-----------------------------------|
| Размер exe          | 39 МБ                       | 4.1 МБ (установщик — 2.1 МБ)      |
| Запуск              | распаковка во временную папку | сразу                           |
| Расчёт распределения | до 4.3 с на тяжёлой квоте, обрыв поиска на 0.5 с | в 13 раз быстрее в среднем, до 23× на тяжёлых |
| Настройки           | реестр Windows              | `%APPDATA%\com.vaponok.logiplan\settings.json` |

При первом запуске программа сама забирает настройки старой версии из реестра
(подразделения, квоты, списки МТО/Лётки, таймеры складов).

## Где взять exe

GitHub → **Actions** → последний запуск «Сборка» → артефакт `logiplan-windows`:

* `logiplan.exe` — переносная программа, просто запустить;
* `logiplan_*_x64-setup.exe` — установщик (ярлык в «Пуске», удаление через «Приложения»).

Для тега `v*` (например `v0.1.0`) те же файлы публикуются в **Releases**.

Нужен WebView2: в Windows 11 он встроен, в Windows 10 обычно уже установлен
обновлениями. Установщик при необходимости скачает его сам.

## Разработка

```bash
npm install
npm run dev          # интерфейс в браузере: http://localhost:1420
npm run tauri dev    # то же в окне Tauri (нужен Rust)
npm test             # сверка с Python-версией (≈5500 случаев) + тесты исправлений
npm run check        # проверка типов
npm run tauri build  # сборка exe (на Windows)
```

## Устройство

```

tools/export_data.py   i18n.py / items.py / quota_writer.py -> src/data/*.json, картинки -> WebP
tools/quota_icons.py   картинки кнопок квоты: иконки игры с вики -> 256x256 WebP (Real-ESRGAN)
tools/golden/          прогон Python-версии на случайных квотах -> tests/golden/*.json
src/core/              логика без интерфейса (перенос из Python)
  splitter.ts            распределение, МТО, Лётка, «Рассчитать квоту», формат вывода
  allocator.ts           fair_allocator: BFD + локальный поиск
  calculator.ts          авиа-калькулятор базовых ресурсов
  quotaParse.ts          разбор строк квоты (CSV, «27 ящ. - …», три языка)
  i18n.ts, py.ts         переводы; совместимость с Python (round, repr(float), strip…)
src/workers/           расчёт в фоновом потоке
src/lib/               состояние, сохранение настроек, импорт из старой версии
src/ui/                вкладки, заголовок окна, диалоги
src-tauri/             Rust: окно, хранилище, чтение реестра старой версии
```

### Как проверяется, что расчёты не сломались

`tools/golden/gen_golden.py` запускает **оригинальный** Python-код (через PyQt5
в режиме offscreen) на тысячах сгенерированных квот: разные форматы строк, три
языка, опечатки, МТО, Лётка, флажки бесплатности. Ответы сохраняются в
`tests/golden/`, а `npm test` требует от TypeScript-версии **совпадения до символа**.

На время прогона в Python-коде меняется только то, что делает его
недетерминированным: снят лимит 0.5 с на поиск (иначе результат зависит от
скорости машины), зафиксирован порядок ресурсов в `preload` (в оригинале он
брался из `set()` и менялся от запуска к запуску) и `x ** 2` заменён на `x * x`.
Кроме того, в эталон на время прогона вносятся те же исправления ошибок старой
версии, что и в TypeScript (см. ниже), — так обе реализации исправлений
проверяют друг друга. Файлы в `legacy/` при этом не меняются.

Пересоздать эталоны (нужны Python 3, PyQt5, Pillow):

```bash
QT_QPA_PLATFORM=offscreen python tools/golden/gen_golden.py --splitter 250
QT_QPA_PLATFORM=offscreen python tools/export_data.py --images <папка images из старого архива>
```

### Картинки «Написания квоты»

Все кнопки — оригинальные иконки игры с [официальной вики](https://foxhole.wiki.gg)
в одном размере 256×256. В самой игре часть иконок 100×100 или 128×128 —
их `tools/quota_icons.py` увеличивает нейросетью Real-ESRGAN (x4plus).
Какой файл вики у какой кнопки — `tools/quota_icons.json`.

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install spandrel pillow numpy
python tools/quota_icons.py --resolve   # дописать новые кнопки в quota_icons.json
python tools/quota_icons.py             # скачать, увеличить, записать public/images/items
```

`export_data.py` ставит кнопкам старые картинки из архива — после него нужно
снова запустить `quota_icons.py`.

## Исправленные ошибки старой версии

1. Квота Лётки понимает свободный формат строк — `2 шт. - Tulka …`,
   `3 ящ. - …`, `1 - …`, с необязательными `[настройками]` в конце. Раньше
   такие строки (а именно так их пишет «Рассчитать квоту») молча
   пропускались — и в разделе Лётки, и в «Ресурсах на завод» по основной
   квоте, и в окне цен самолётов.
2. Если в «Модификациях» один предмет указан двумя строками и обе достаются
   одному человеку, количества складываются (раньше второе затирало первое).
3. Предметы Лётки без записи в `resources.json`, но известные по названию
   («Одеяние авиатора», «Рюкзак парашютиста», «Cloudrunner’s Vesture»),
   делятся между лётчиками. Совсем нераспознанные строки Лётки попадают в
   «Неизвестные позиции», а не пропадают молча.

Улучшения относительно старой версии: поиск в редакторах МТО/Лётки ищет и по
названию на текущем языке; язык и последняя вкладка запоминаются; поле
«Написание квоты» сохраняется между запусками; у результата есть кнопка «Копировать».
