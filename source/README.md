# Logiplan — исходники

Tauri 2 (Rust) + Svelte 5 + TypeScript. Перенос Python/PyQt5-версии
(`legacy/`) с сохранением всех расчётов до символа.

## Команды

```bash
npm install
npm run dev          # интерфейс в браузере: http://localhost:1420
npm run tauri dev    # то же в окне Tauri (нужен Rust)
npm test             # сверка с Python-версией + тесты исправлений
npm run check        # проверка типов
npm run tauri build  # сборка exe (на Windows)
```

exe собирает GitHub Actions (`.github/workflows/build.yml`) при каждом push в
`main` и кладёт `logiplan.exe` в корень репозитория. Установщик — в артефакте
сборки `logiplan-windows`.

## Устройство

```
src/core/      логика без интерфейса: распределение, аллокатор, авиа-калькулятор,
               разбор строк квоты, переводы; calcHost.ts — расчёт в фоновом потоке
src/lib/       состояние, сохранение настроек, импорт из старой версии
src/ui/        вкладки, заголовок окна, диалоги
src/data/      данные в JSON (генерируются скриптами из tools/)
src-tauri/     Rust: окно, хранилище, чтение реестра старой версии
legacy/        исходники Python-версии без изменений — эталон поведения
tools/         выгрузка данных, иконки, склады, генератор эталонов
tests/         сверка с эталонами
```

## Проверка расчётов

`tools/golden/gen_golden.py` прогоняет **оригинальный** Python-код на тысячах
сгенерированных квот и сохраняет ответы в `tests/golden/`; `npm test` требует
от TypeScript-версии совпадения до символа. На время прогона в Python-коде
убирается недетерминированность (лимит времени поиска, порядок `set()`,
`x ** 2` → `x * x`) и вносятся те же исправления и изменения игры, что и в
TypeScript. Файлы в `legacy/` не меняются.

```bash
QT_QPA_PLATFORM=offscreen python tools/golden/gen_golden.py --splitter 250
```

## Данные

| Скрипт | Что делает |
|---|---|
| `tools/export_data.py` | `legacy/*.py` → `src/data/*.json` (переводы, ресурсы, списки) |
| `tools/data_updates.py` | изменения игры поверх данных старой версии; применяются и в экспорте, и в эталонах |
| `tools/quota_icons.py` | иконки «Написания квоты» с foxhole.wiki.gg, 256×256, мелкие увеличены Real-ESRGAN |
| `tools/draw_pallet.py` | иконка поддона, нарисованная заново |
| `tools/depots.py` | регионы и склады из War API игры → `src/data/depots.json`; перезапускать при смене карты |

```bash
QT_QPA_PLATFORM=offscreen python tools/export_data.py   # нужны PyQt5 и Pillow
python tools/quota_icons.py                             # нужны torch, spandrel, pillow, numpy
python tools/depots.py
```

## Отличия от старой версии

Изменения игры (`tools/data_updates.py`):
- Rooster - Lamploader, Tumblebox и Junkwagon — ящики массовой фабрики,
  300 бмат, по 5 в очереди; Lamploader и Tumblebox убраны из завода.

Исправленные ошибки:
- квота Лётки понимает свободный формат строк (`2 шт. - …`, `1 - …`,
  с `[настройками]`) — раньше такие строки молча пропадали;
- повторные строки одной модификации МТО у одного человека складываются,
  а не затирают друг друга;
- предметы Лётки без записи в `resources.json`, но известные по названию,
  делятся между лётчиками; нераспознанные — в «Неизвестных позициях».

Новое: единицы «ящ./шт.» на языке интерфейса, гекс/склад/пароль в таймерах,
сворачиваемые разделы, поиск в редакторах МТО/Лётки на текущем языке,
кнопка «Копировать» у результата.
